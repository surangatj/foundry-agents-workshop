Lab 8 · Governance and guardrails

Dialog Care Copilot — build it step by step.

⏱ 15 minStretchGovernanceGuardrailsHuman-in-the-loop
Theory recap · Governance is layered: identity (each agent gets a Microsoft Entra Agent ID), least privilege (only the tools it needs), human approval for risky actions, guardrails (Prompt Shields, content filters, task adherence) on inputs, outputs and tool calls, and the Foundry Control Plane to inventory, monitor and stop agents across the organisation.
In this lab you will
  • Require a supervisor's approval before money is credited
  • Attack your agent and see what's blocked
  • Find your agent in the Control Plane

Steps

  1. Human approval

    labs/lab08_governance.py
    apply_bill_credit = tool(_credit_tool.func, name="apply_bill_credit",
                         description=_credit_tool.description,
                         approval_mode="always_require")
    python -m labs.lab08_governance

    Answer y or n when the agent asks to credit the account.

  2. Attacks

    The same script sends a jailbreak, a social-engineering prompt and an indirect injection hidden in a customer email. Note which are stopped by the guardrail (an API error) and which by the instructions.

  3. Explore the portal

    • Operate → Assets: every agent in the project, its versions and owners.
    • Your agent → Guardrails: the policy applied to it.
    • Your agent → Identity: its Entra Agent ID.
