Lab 7 · Distillation

Dialog Care Copilot — build it step by step.

⏱ 15 minStretchFine-tuningDistillation
Theory recap · Fine-tuning adapts a model to your task: SFT (learn from examples), DPO (learn preferences), RFT (learn from a grader). Distillation is SFT where a large teacher writes the examples for a small student — you keep most of the quality at a fraction of the cost and latency, without the long grounding prompt.
In this lab you will
  • Let the teacher generate questions and answers
  • Write a chat-format training set
  • (Optional) submit a fine-tuning job for the student

Steps

  1. Build the dataset (cheap)

    python -m labs.lab07_distillation

    Open data/distill/train.jsonl. Each line is one conversation in the format the fine-tuning API expects.

  2. Submit training (only if the facilitators say so)

    python -m labs.lab07_distillation --submit
    Cost & time: training takes 30–120 minutes and is billed. Global Training processes data outside Sri Lanka — check data-residency rules before using real customer data.

  3. Compare teacher vs student

    The facilitators trained a student before the session. In Foundry open Build → Fine-tuning and look at the training/validation loss, then run the same Lab 5 evaluation against it.

🧪 Try it: Foundry can also build the training set straight from your agent's production traces (dataset generation from traces, preview).
