Lab 2 · Ground it with Foundry IQ

Dialog Care Copilot — build it step by step.

⏱ 20 minCoreFoundry ToolsFoundry IQRAG
Theory recap · Agents must answer from Dialog's documents, not from memory. Two options: the built-in File Search tool (a vector store inside the project) or a Foundry IQ knowledge base — agentic retrieval on Azure AI Search that plans sub-queries, searches several sources and returns cited answers through one MCP tool, knowledge_base_retrieve.
In this lab you will
  • Index the five sample policy documents
  • Answer customer questions with citations
  • See the agent refuse to invent a tariff
  • Connect to a shared Foundry IQ knowledge base

Steps

  1. Look at the knowledge

    Open data/knowledge/: prepaid packages, postpaid billing, roaming, troubleshooting and customer policies (all fictional, in LKR).

  2. Part A — File Search

    python -m labs.lab02_foundry_iq

    The script uploads the files to a vector store, attaches the file_search tool and asks five questions — including one in Sinhala and one whose answer is not in the documents.

  3. Part B — Foundry IQ knowledge base

    The facilitators built one shared knowledge base on Azure AI Search over the same documents. Add the values they share to .env, then:

    .env
    FOUNDRY_IQ_MCP_URL=https://<search>.search.windows.net/knowledgebases/<kb>/mcp?api-version=...
FOUNDRY_IQ_CONNECTION_ID=<project connection id>
    python -m labs.lab02_foundry_iq --iq
    How the agent connects
    knowledge_tool = client.get_mcp_tool(
    name="dialog_knowledge_base",
    url=url,
    allowed_tools=["knowledge_base_retrieve"],
    approval_mode="never_require",
    project_connection_id=os.getenv("FOUNDRY_IQ_CONNECTION_ID"),
)

  4. Explore it in the portal

    In Foundry open Build → Knowledge to see the knowledge base, its sources and the retrieval reasoning setting. Try a question in the knowledge base playground.

🧪 Try it: Change a roaming price in data/knowledge/03_roaming_guide.md, re-run Part A and watch the answer change.

Troubleshooting

Part B returns 401/403

The project connection or your Search role is missing — Part A covers the same idea; carry on with it.
