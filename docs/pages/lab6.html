Lab 6 · The improvement loop

Dialog Care Copilot — build it step by step.

⏱ 20 minCoreContinuous improvementAgent versionsEvaluations
Theory recap · Production agents improve through a signal loop: observe (traces, user feedback) → measure (evals) → diagnose (cluster failures) → fix (instructions, tools, knowledge, model) → re-measure on the same test set → ship a new version with a canary. In Foundry, continuous evaluation rules score live traffic and failing traces become new test cases.
In this lab you will
  • Diagnose the v1 failures
  • Publish v2 with better instructions and grounding
  • Re-run the same evaluation and compare runs

Steps

  1. Diagnose

    From Lab 5: which questions failed and why? Typical: no package codes, wrong language, invented prices.

  2. Fix

    Edit V2_INSTRUCTIONS in labs/lab06_improvement_loop.py. It already adds the knowledge and rules — make it better.

  3. Re-measure

    python -m labs.lab06_improvement_loop

    In Foundry: Evaluations → your eval → select the v1 and v2 runs → Compare.

  4. Close the loop in production (discussion)

    • Continuous evaluation rule — score a sample of live responses every hour.
    • Agent Insights / trace clustering — group failures by root cause.
    • Agent optimization jobs — try prompt/model variants against your evaluators.
    • Versioned rollout — route 10% of traffic to v2, watch the scores, then promote.
🧪 Try it: Add three failing real-world questions to the JSONL test set — that's how a regression suite grows.
