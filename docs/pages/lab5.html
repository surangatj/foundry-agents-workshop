Lab 5 · Observe and evaluate

Dialog Care Copilot — build it step by step.

⏱ 25 minCoreObservabilityTracingEvaluations
Theory recap · You can't improve what you can't see. Tracing (OpenTelemetry → Application Insights) records every model call, tool call, token and latency. Evaluations score answers at scale with built-in AI judges — task adherence, intent resolution, tool-call accuracy, groundedness, fluency — plus your own deterministic checks.
In this lab you will
  • Send traces to Foundry and read them
  • Publish a v1 agent version to Foundry Agent Service
  • Run a cloud evaluation over 12 test questions in 4 languages

Steps

  1. Tracing

    python -m labs.lab05_observe_and_evaluate --trace
    One line enables it
    await client.configure_azure_monitor(enable_sensitive_data=True)

    In Foundry: Build → Agents → Traces (allow 2–5 minutes). Open a trace and find the verify_customer tool span and its token counts.

  2. Look at the test set

    data/eval/care_questions.jsonl — English, Sinhala, Tamil and Singlish questions, each with the fact the answer must contain (e.g. RM-ASIA-7).

  3. Run the evaluation

    python -m labs.lab05_observe_and_evaluate --eval

    This publishes <alias>-faq-agent v1 (deliberately thin instructions) and evaluates it. Copy the printed EVAL_ID=… line into .env.

  4. Read the results

    The terminal shows pass rates and failing questions. In Foundry open Evaluations to drill into each row and the judge's reasoning.

Troubleshooting

No traces appear

The project needs Application Insights connected (Project → Tracing). Ingestion can take 5 minutes.

Eval run is slow

Cloud runs queue with everyone else's — 3–8 minutes is normal. Read the traces while you wait.
