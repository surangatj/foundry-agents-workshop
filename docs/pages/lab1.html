Lab 1 · Your first agent

Dialog Care Copilot — build it step by step.

⏱ 20 minCoreFoundry Agent ServiceMicrosoft Agent FrameworkFoundry Tools
Theory recap · Microsoft Agent Framework is the open-source SDK (successor to Semantic Kernel + AutoGen) for building agents in Python or .NET. Its FoundryChatClient runs the agent on Foundry Agent Service through the Responses API. An agent = model + instructions + tools.
In this lab you will
  • Create an agent in code
  • Give it Python function tools (customer verification, bills, outages)
  • Add a built-in Foundry tool (code interpreter)
  • Hold a multi-turn conversation with a session

Steps

  1. Read the code first

    Open labs/lab01_first_agent.py and labs/common/dialog_tools.py. A tool is just a Python function with a docstring and typed parameters:

    labs/common/dialog_tools.py
    @tool(approval_mode="never_require")
def check_network_outage(
    district: Annotated[str, Field(description="Sri Lankan district, e.g. Colombo, Kandy, Jaffna")],
) -> str:
    """Check for active network outages in a district."""

    And the agent is three lines:

    labs/lab01_first_agent.py
    agent = Agent(
    client=client,
    name="dialog-care-copilot",
    instructions=INSTRUCTIONS,
    tools=[*ALL_TOOLS, client.get_code_interpreter_tool()],
)

  2. Run the scripted conversation

    python -m labs.lab01_first_agent

    Watch it verify Nimal (mobile + NIC digits), fetch his bill, explain the VAS charge and use the code interpreter to total two months.

  3. Chat with it yourself

    python -m labs.lab01_first_agent --chat

    Test customers you can use:

  4. Break the rules on purpose

    Ask for a bill without giving the NIC digits, or give the wrong ones. The tool refuses and the instructions make the agent ask again. Guardrails start with good tool design.

🧪 Try it: Ask in Sinhala: මගේ data ඉවර වෙලා. 0772345602, NIC 7788. Then add a new tool — e.g. get_care_centre_hours(city) — and ask about Poya-day opening hours.

Troubleshooting

The agent never calls my tool

Check the docstring and parameter descriptions — that's all the model sees. Make the instructions say when to use it.
