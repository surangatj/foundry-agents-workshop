Lab 3 · Multi-agent workflow

Dialog Care Copilot — build it step by step.

⏱ 25 minCoreMulti-agentOrchestrationHandoff
Theory recap · One agent with 20 tools gets confused. Split the job: a triage agent routes to billing, network and roaming specialists, each with only the tools it needs. Agent Framework ships orchestration patterns — sequential, concurrent, handoff, group chat, magentic — plus graph-based workflows with checkpoints and human-in-the-loop.
In this lab you will
  • Build four agents with least-privilege tools
  • Wire them with HandoffBuilder
  • Watch control pass between agents in one conversation

Steps

  1. Read the orchestration

    labs/lab03_multi_agent_handoff.py
    workflow = (
    HandoffBuilder(name="dialog_care_handoff",
                   participants=[triage, billing, network, roaming],
                   termination_condition=...)
    .with_start_agent(triage)
    .build()
)

    HandoffBuilder generates the handoff tools for you — the triage agent just decides who should take over.

  2. Run it

    python -m labs.lab03_multi_agent_handoff

    Tharushi reports no 4G in Peradeniya (there's an outage), then asks about Singapore roaming. Look for the 🔀 handoff lines.

  3. Compare the patterns

    PatternUse it whenDialog example
    SequentialFixed pipelineSummarise complaint → classify → draft reply
    ConcurrentIndependent experts in parallelNetwork, billing and fraud checks on one ticket
    HandoffConversation moves between specialistsThis lab
    Group chatAgents debate / reviewWriter + compliance reviewer for a tariff announcement
    MagenticOpen-ended task, manager plansInvestigate a district-wide churn spike
🧪 Try it: Add a fibre_agent for home broadband with only check_network_outage and raise_support_ticket, and send a Tamil fibre complaint from Jaffna (there's planned maintenance in Nallur).

Troubleshooting

It loops between agents

Tighten the triage instructions and make the termination condition explicit.
