Prerequisites

Please complete these before Monday morning.

  1. Access to a Microsoft Foundry project with a model

    API-key option: get the project endpoint, deployment name and resource key from the facilitators. Set FOUNDRY_API_KEY in .env; Azure CLI and personal Azure sign-in are not required.

    Either access to a Foundry project that already has a chat model deployed (recommended gpt-5.4-mini), or permission to deploy one yourself. The workshop uses the Southeast Asia region.

    Check: open ai.azure.com → your project → copy the project endpoint from Overview and the deployment name from Models → say “Ayubowan!” in the Playground. You need at least the Foundry User role.

  2. A GitHub account

    Personal accounts are fine. Codespaces includes free monthly hours — the workshop uses about 10.

  3. A laptop with Chrome or Edge

    Nothing to install with Codespaces. Optional local alternative: VS Code, Python 3.13 and Git. Azure CLI is needed only for personal Azure sign-in.

  4. Test sign-in from a Codespace (5 minutes — important)

    Open in Codespaces ↗

    API-key users: configure .env and run python -m labs.lab00_check_setup. Otherwise, test personal Azure sign-in:

    az login --use-device-code

    If your Dialog sign-in is blocked, reply to the invitation before Monday so we can arrange a fallback.
